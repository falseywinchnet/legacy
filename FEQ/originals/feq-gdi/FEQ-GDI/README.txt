Full EQuations - Graphical Data Inspector (FEQ-GDI) -- A tool  for viewing FEQUTL data and
efficiently identifying errors

The FEQUTL GDI requires Java 1.7 or higher to run. It can run on Windows, Machintosh and Linux
operating systems.

INSTALLATION

The FEQUTL GDI requires no installation, and can simply be run by unzipping the
FEQ-GDI.zip archive and executing the FEQ-GDI.jar file inside. 

RUNNING FEQ-GDI

Double-click the executable JAR file FEQ-GDI.jar in the unzipped FEQ-GDI archive folder. 
If you are using a command line, go to the directory containing FEQ-GDI.jar and enter the
following: java -jar FEQ-GDI.jar

The FEQ-GDI archive folder also contains a set of example files that can be used
with the FEQ-GDI to show proper file format and GDI function.
