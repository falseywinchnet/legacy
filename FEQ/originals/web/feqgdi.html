FEQ-GDI

FEQ Graphical Data Inspector (FEQ-GDI) is a menu-driven utility program that enables users to visualize the geometric and hydraulic properties of channel cross sections, selected control structures, and stream profiles for FEQ and FEQUTL fixed-format input files. It is documented in U.S. Geological Survey Open-File Report 2019-1113, and runs on Microsoft Windows operating systems. FEQ-GDI is written in Java and distributed as an executable JAR file. It requires that Java 1.7 or higher is installed on the computer, and has been tested on MS Windows versions 7, 8, and 10. To install FEQ-GDI, download and save the distribution file, then use File Explorer to unzip the archive, navigate to the FEQ-GDI directory, and double click on the FEQ-GDI.jar file. Example files are included in the "sample files" directory included in the FEQ-GDI.zip file.
