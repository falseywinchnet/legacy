FEQinput

FEQinput is a line editor for FEQ and FEQUTL input files that includes built-in context sensitive help. It is documented in U.S. Geological Survey Fact Sheet 2017-3072, and runs on Microsoft Windows operating systems. FEQinput is distributed as a 32-bit Windows Installer (MSI) file, and may require administrative privileges to install. It has been tested on MS Windows versions 7, 8, and 10, and works best on FEQ version 10.61 or higher input files. To install FEQinput, download and save the distribution file, then use File Explorer to navigate to the download directory and double click on the FEQinput MSI file.
