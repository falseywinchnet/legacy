TABDIR is a program that creates a directory of function tables for
an FEQ model.  TABDIR requires two command line arguments.
The first argument is a file name that contains the names
of the function table files to be scanned.  The contents
of an example file are:

These are copied from the Function Tables block of an existing 
FEQ model. The last line in the file should be a blank line. 
Notice that all of the names in this example are fully qualified.
They need not be so but if they are not you must make sure that
the directory in which you run TABDIR will be the correct directory.

The number of files is given first with the file names in the order in which
they were given.  This is followed by a numerically ascending list
of table numbers with the type of the table, the file name that 
contains the table, and a label for the table.  In some cases the 
label will be based on informal practice on the part of users.  
In others the label is extracted from the explicit label field
of the table. 


The current size limits for the executable file are:

number of function-table files:  500

number of function tables: 5000
